# Fonts

Self-hosted so pages don't depend on (or leak visitors to) a font CDN. The
`@font-face` rules are in `static/sass/_fonts.scss`.

WOFF2 files from [Fontsource](https://fontsource.org) 5.3.0, latin and latin-ext
subsets only:

- **Boldonse** 400: Copyright 2024 The Boldonse Project Authors
  (https://github.com/googlefonts/boldonse)
- **Cabin** 400, 500, 600, 700: Copyright 2018 The Cabin Project Authors
  (https://github.com/impallari/Cabin)
